# AI Snake Lab

The AI Snake Lab is a headless version of the classic Snake game with an AI agent as the player. It is a [reinforcement-learning sandbox](/snake-lab/rl-sandbox) where the AI is a compact Q-learning agent implemented in NumPy. Akbar proposes three experiment settings:

- [Learning rate](/snake-lab/learning-rate)
- [Initial epsilon](/snake-lab/initial-epsilon)
- [Epsilon decay](/snake-lab/epsilon-decay)
