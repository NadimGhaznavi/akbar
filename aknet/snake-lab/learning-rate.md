# Learning Rate

The learning rate controls the size of each Q-function parameter update during training.

- A value that is too high can make learning unstable.
- A value that is too low can make improvement slow within 1500 epochs.
- Akbar proposes a baseline and the experiment runs values five percent below and above it as well as the baseline.
- Interpret learning-rate effects using the complete 27-simulation experiment population.
