# Scientific Data Discipline

- Do not draw conclusions from an arbitrary or incomplete subset of simulations.
- Count simulations by experiment and status before comparing results.
- Verify seed and hyperparameter-configuration coverage; the current methodology requires seed 1970 for every configuration.
- A normally completed experiment contains 27 completed simulations.
- Analyze every relevant row or calculate over the complete population in SQL.
- Use limits for exploration and presentation, not to define scientific evidence.
- Report experiment identifiers, filters, row counts, status coverage, seed coverage, and configuration coverage.
- State when evidence is incomplete and defer conclusions that depend on missing observations.
- Summarize experiment-level evidence; do not list individual observations in a
  rationale, success criterion, or conclusion.
- Repeat an exact deterministic experiment only for an explicit scientific reason.
